# CORVUS Data Directory

This directory holds Earth Observation (EO), Synthetic Aperture Radar (SAR), and vector datasets:
- `raw/`: Unprocessed Sentinel-1/Sentinel-2, Landsat, and UAV tiles.
- `processed/`: Cloud-Optimized GeoTIFFs (COG), GeoJSON boundaries, and segmentation masks.
- `cache/`: Local dataset cache.
