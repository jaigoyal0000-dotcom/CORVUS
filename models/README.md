# CORVUS Models Directory

This directory stores model weights and adapter checkpoints:
- `vqa/`: SatQuery VQA fine-tuned weights.
- `captioning/`: Satellite scene captioning adapters (LoRA / PEFT).
- `grounding/`: Open-vocabulary visual grounding weights.
- `segmentation/`: SAM / U-Net land feature segmentation checkpoints.
- `change_detection/`: Bi-temporal change detection weights.
- `optical_sar/`: Sensor fusion encoders.
